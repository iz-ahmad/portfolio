Personal portfolio site. Next.js 15 + React 19, TypeScript. Static export enabled.

### Stack

Next.js 15, React 19, and TypeScript

### Setup

```bash
# Install
npm install

# Dev server
npm run dev

# Build static export
npm run build

# Preview built site
npm run start
```

### Project Structure

```
out/                      # Static assets
src/
├── app/
│   └── page.tsx          # Server component
├── components/           # 12+ sections
├── data/                 # JSON
├── hooks/                # Custom hooks
├── lib/
│   └── sfx.ts            # Sound effects
├── styles/               
├── types/                # TypeScript types
```
